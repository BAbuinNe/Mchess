# MChess

Русскоязычное шахматное веб-приложение по техническому заданию. Сейчас это работающая локальная версия и сервер приватных партий, а не завершённый публичный релиз.

## Запуск

Нужны Node.js 24 и npm. В Windows можно запустить `START_HERE.cmd` двойным щелчком. Или в папке `outputs/mchess` выполните:

```powershell
npm install
npm run dev
```

Откройте `http://localhost:5173`. Для игры с другом на другом устройстве используйте адрес компьютера в локальной сети и разрешите входящие соединения на порты 5173 и 3001. При отдельном размещении API задайте `VITE_API_URL` в `apps/web/.env` до сборки.

Проверка сборки: `npm run build`. Для локального просмотра собранной PWA: `npm run preview -w @mchess/web`.

## Android APK

Актуальный установочный debug-файл: `MChess-test-2026-11-07-v4.apk`. Он подписан отладочным ключом и подходит для прямой установки на Android 7.0 (API 24) и новее. Локальная партия, Stockfish, задачи и текущий анализ работают без онлайн-сервера. Онлайн в APK требует доступного HTTPS API; его адрес задаётся в профиле. Публичный сервер пока не развёрнут.

Чтобы пересобрать APK после изменений: `npm run build -w @mchess/web`, затем из `apps/web` — `npx cap sync android`, затем из `apps/web/android` — `gradlew.bat assembleDebug` с настроенными `JAVA_HOME` (JDK 21) и `ANDROID_HOME`.

## Что работает

- Партия на одном устройстве с полной проверкой правил `chess.js`, превращением пешки и сохранением PGN в браузере.
- Игра белыми против Stockfish 19 Lite с 12 настройками сложности. Числа 200–2800 пока служат названиями уровней, не измеренным Elo.
- Оценка текущей позиции и лучший ход от Stockfish на экране анализа; импорт и скачивание PGN.
- Три интерактивные учебные позиции с подсказками и сохранением прогресса.
- Приватная онлайн-комната по ссылке: два места, проверка ходов сервером, часы 10+0, предложение ничьей, сдача, WebSocket и восстановление партии после перезапуска сервера.
- Выбор одного из четырёх тренеров. При выборе Мелстроя три подготовленных прозрачных ролика воспроизводятся на соответствующих событиях игры и задач. Привязка роликов основана на черновой расшифровке и ещё требует ручной проверки речи.
- Веб-приложение с манифестом и service worker для офлайн-загрузки уже посещённых ресурсов.

## Что остаётся по плану

Публичный хостинг и PostgreSQL, аккаунты и рейтинг Glicko-2, подбор соперника, продвинутый разбор каждого хода и объяснения тренеров, полная Академия и база задач, музыка, настройки, друзья и Android-сборка. Онлайн-сервер сейчас хранит комнаты в `apps/server/data/rooms.json`; для публичного размещения нужен постоянный диск и процесс с WebSocket.

## Единый сервер для сайта и партий

После `npm run build` команда `npm run start -w @mchess/server` отдаёт веб-сайт, API и WebSocket с одного адреса (порт `PORT`, по умолчанию 3001). Проверка: `npm run test:server-static` и `npm run test:online`. Для контейнерного хостинга добавлен `Dockerfile`; каталог `/data` обязателен как постоянный том, иначе профили, комнаты и рейтинг потеряются при перезапуске. Публичного развёртывания ещё нет. GitHub Pages может разместить только статический сайт и не запускает этот WebSocket-сервер.
